# BaliGuide для беларусиков

Гид по Бали для граждан Беларуси: въезд и документы, законы, здоровье, транспорт, море, еда, активности, красивые места, зимовка, «Рекомендасьёны» из Threads и Instagram, «Карта рядом», «Мой список» и Балийский тигрус.

## Что здесь лежит

- `index.html` — весь гайд: одна страница, работает прямо в браузере, без сборки.
- `tiger-fur.jpg` — фото меха тигра для шапки (Mathias Appel, CC0, Wikimedia Commons).

## Как менять

- Через Claude: написать, что поменять, — правка и публикация делаются за вас.
- Скоро: админ-панель гайда — правки карточек прямо с телефона.

Каждое изменение сохраняется в истории этого хранилища — любую версию можно вернуть.
